# BBS 扩展 — Better camera perspective 使用说明

版本 **V1.7.3**（2026-11-01）

> **版本关系**：V1.7.3 在 V1.7.2 基础上转正，整合 POV Actions 翻译补全与剪辑交互改进。V1.7.2 及更早正式版本已归档至 `历史版本归档/`。

面向 BBS FS 影片编辑器的摄像机增强插件：核心为「多样追踪」剪辑（追踪 + 关键帧二合一、相对/绝对双值联动、游动/追踪双路线），配套相位追踪、anchor 追踪轴、关键帧展开模式、剪辑可见性筛选、POV 插件中文翻译补充、功能冲突检测、可视化布局等，以及设置页内的「往期日志」子设置页。

个人插件（语雀）：https://www.yuque.com/huangyingxuanyan/krkn1x/gugz9cdalyvuo7d3?singleDoc# 《Better camera perspective》

## 一、整体功能

### 1. 「多样追踪」剪辑 —— 追踪器 + 关键帧二合一

新增剪辑「多样追踪」（橙色图标），在原有「追踪器」剪辑（仅静态追踪演员）基础上叠加完整的关键帧编辑能力，相当于**有追踪能力的「关键帧」剪辑**。

剪辑面板从上到下：

| 选项 | 说明 |
| --- | --- |
| **编辑** | 打开关键帧编辑器（X / Y / Z / 偏航 / 俯仰 / 横滚 / 视野 / 距离 / 锚点），操作方式与「关键帧」剪辑一致 |
| **叠加** | 关键帧以叠加（增量）方式生效，同「关键帧」剪辑的 additive |
| **目标 / 附件** | 选择要追踪的演员与骨骼部位（同「追踪器」） |
| **偏移 / 角度** | 相对追踪点的偏移与视角角度 |
| **看向目标 / 相对** | lookAt 模式 / 相对模式 |
| **启用位掩码**（0–5 共 6 位） | 位 0–2 = X/Y/Z 位移跟随；位 3–5 = 偏航 / 俯仰 / 横滚跟随。默认 6 位全开 = 纯追踪器行为；**关掉某一位后，该轴改由关键帧曲线驱动**——这就是「多样追踪」的核心玩法 |

* 选中剪辑后拖动相机：先按追踪器方式反解偏移 / 角度，再把相机位置写入关键帧曲线。
* 视野（fov）不做位掩码，始终由关键帧通道驱动。

### 2. XYZ 双值联动编辑

选中 X/Y/Z 通道的关键帧时，值面板**同时显示两个数值**：

* **相对值**：该视角相对于被绑定模型及部位（或默认位置）的相对偏移；
* **绝对值**：该视角在地图上的绝对坐标。

两个值**任改其一，另一个自动同步换算**（绝对 = 相对 + 该时刻追踪锚点），数值始终一致、画面不跳变。播放时 XYZ 关键帧按相对值语义生效（锚点 + 偏移合成）；不设追踪目标时相对值 = 绝对值。

### 3. XYZ 关键帧主继承模式：游动 / 追踪双路线

「相对值」「绝对值」两个行首按钮是可点击的**主继承模式开关**（选中 = 黄色高亮，点击即应用）：

* 按钮文本随当前路线自动切换，两条路线**各自独立记忆、互不串用**：
  * **游动路线**（anchor 未绑定任何模型时自动生效）：`游动·相对`（默认，XYZ 存绝对坐标）/ `游动·绝对`（XYZ 存绝对坐标，播放直接用）；
  * **追踪路线**（anchor 绑定模型时自动生效）：`追踪·相对`（默认，XYZ 存「相对锚点的偏移」，播放按「锚点 + 偏移」合成）/ `追踪·绝对`（XYZ 存绝对坐标，播放直接使用）；
* 切换只影响后续新建关键帧的**继承值**，当前关键帧与视角状态不受影响；相对 / 绝对两值的联动换算保持不变。

新建多样追踪剪辑默认在 tick 0 放一个**空 anchor 关键帧**作为分派依据——anchor 未绑定自动走「游动」，绑定模型自动走「追踪」。

### 4. 空通道新建关键帧继承摄像机当前视角

* X / Y / Z 通道为空时新建关键帧，自动继承**预览摄像机位置 − 追踪锚点**（相对偏移）；无锚点时按游动路线存绝对坐标；
* 偏航 / 俯仰 / 横滚 / 视野通道为空时新建关键帧，自动继承**预览摄像机当前角度与视野值**；
* 继承的角度值统一归一化到 (-180, 180]，不会出现差一整圈的异常旋转；
* 播放时若播放头不在任何关键帧段，回退到进入剪辑前的相机位置 / 角度，不会被读成 0。

### 5. anchor 追踪轴

多样追踪关键帧编辑器在 8 通道之外，新增 **「锚点」** 通道（蓝色）。锚点通道的关键帧值 = **追踪目标**（演员 + 模型部位）：

* **通道无关键帧**（或关键帧为空值）→ 追踪目标使用剪辑属性的「目标 / 附件」绑定；
* **通道有关键帧且值非空** → 该时刻追踪目标以 anchor 轴数值为主（覆盖剪辑属性绑定）；
* **相邻关键帧绑定不同目标**（如 1tick 绑模型一头部、20tick 绑模型二脚部）→ 播放时在两个目标的追踪结果之间**平滑插值过渡**，避免画面跳变。

编辑方式：进入剪辑「编辑」→ 选中「锚点」通道 → 时间轴打点 → 在关键帧值面板选演员与部位（或吸管直接点选场景中的演员 / 部位）。

绑定目标 / 切换部位后，仅当当前帧有**有效的追踪锚点**时才把该帧写为「相机位置 − 锚点」（贴回锚点）；锚点无效时保留原值，不会被写成 0。

### 6. 锚点显示与绑定列表

* **显示名伪装名优先**：演员 / 模型的绑定列表中，有可辨识名（自定义名 → 表单名 → 资产库同类型伪装名 → 影片内同类型演员名）时直接显示该名字，不再带「ID串 - formId」前缀；确实没有可辨识名时才用「类型友好名 + 原 ID」兜底。
* **完整演员列表**：列表显示影片全部演员（含新建 / 未实例化），按组 / 类别做二级选择；菜单可滚动，演员条目 ≥ 12 个时自动出现搜索过滤框。

### 7. 剪辑可见性筛选「可视性设置」

* **入口**：摄像机编辑器右键菜单 1 号位「可视性设置」；
* **行为**：自由勾选想隐藏 / 想保留的剪辑；
* **排布模式**（由「可视化设置」→「可视化筛选排布」控制）：
  * `[动态]` —— 筛选后列表自动重排（可见剪辑排前，隐藏剪辑沉底）；
  * `[静态]` —— 筛选后不重排，被隐藏的剪辑在此界面的布局位置不变；
* **多列自适应**：一列上限 10 个剪辑，超出放入下一列，列数上限 5（理论容纳 49 个剪辑）；
* **面板尺寸**：水平 / 垂直各削减 40%；
* **持久化**：退出 BBS 页面时读取并存储当前可视性设置，恢复全开（避免缺少本插件时崩溃）。

### 8. 关键帧处理设置

设置页「摄像机编辑设置」→「关键帧处理设置」：

* **关键帧被选中状态**三模式（并列可选按钮，选中即应用）：
  * `[默认]` —— 新建关键帧后全部保持选中；
  * `[单体]` —— 每新建一个关键帧自动解除上一个的选中；
  * `[混合]` —— 连续新建只保留最新帧选中，手动选中的帧不受影响。
* **关键帧展开模式**（控制动画编辑器中关键帧轨道的展开方式）：
  * `[默认]` —— BBS 2.7 现状：打开 / 切换部件后关键帧轨道折叠；
  * `[原始]` —— 一次性展开所有部件关键帧轨道；被可视度筛选排除的轨道不会展开。

### 9. 可视化设置

设置页「摄像机编辑设置」→「可视化设置」，含两个独立设置项（并列可选按钮，选中即应用）：

**① 预创建剪辑可视化** —— 右键添加剪辑菜单的布局：
* `[原始]` —— 自适应多列动态布局；
* `[覆盖]` —— 顶部搜索框 + 「覆盖 / 修改器 / 杂项」三列分类菜单（分类标题着色，搜索即时过滤）。

剪辑分类规则：**覆盖** = 静止 / 路径 / 关键帧 / 追踪器 / Spline / 多样追踪 / 跟随 / 闲置；**修改器** = 平移 / 角度 / 阻力 / 摇晃 / 数学 / 重映射 / 看 / 轨道 / 滑动变焦 / 电影；其余归**杂项**兜底。

**② 可视化筛选排布** —— 可视性设置面板的排布：动态重排 / 静态保留原位。

### 10. 功能冲突检测设置页

设置页左侧导航 2 号位（1 号位往期日志之后）「功能冲突检测」。每个功能独立统计来源数（BCP=1，检测到其他插件 +1），来源数 ≥ 2 才显示对应按钮组，让用户手动选择翻译优先级（第三方优先 / BCP 优先 / 第三方为主 BCP 辅助）。

### 11. 往期日志

设置页「摄像机编辑设置」内「往期日志」子设置页（1 号位最上方）：各版本更新履历以 .md 格式随 mod 打包、设置页内直接滚动查看（版本标题黄色高亮、引用说明灰色缩进）。

### 12. POV 插件中文翻译补充

针对 POV 插件（BBS-POV）做的补充性中文翻译补丁：

* **触发条件**：Cubed 的「中文关键帧轨道名称」开关打开时自动生效；
* **翻译范围**：
  * POV 时间轴子页轨道名（hotbar、Hand、POV Action 三个子页）；
  * POV Action 右键菜单的 action 类型名（GUI、Menu、Camera Shake、Particle Effect、Boss Bars、Status Effects、Toasts、Chat、Screen Effect）；
  * POV Action 属性面板里的 label 文字（400+ 条显示名，含屏幕特效列表效果名、Boss 血条面板、编辑器按钮等）；
* **预防性补丁**：优先调用 Cubed 的翻译接口，Cubed 已覆盖则用 Cubed 的结果，只有 Cubed 没覆盖到的才用本插件翻译表，避免冲突崩溃；
* **未翻译字符串自动日志**：遇到翻译表未覆盖的字符串会自动打印 debug 日志（Logger: `BCP-PovTranslator`），便于后续补全。

## 三、安装

1. 环境：Minecraft **1.20.1（Fabric）** + **Fabric API**
不要以 **Forge** 环境下加载此 mod，也不要使用**信雅互联**，会变得不幸；
2. 将 `better-camera-perspective-V1.7.3.jar` 放入 `.minecraft/mods`；
3. 确保 **BBS FS 2.7**（`bbs-2.7-1.20.1.jar`）在 mods 中；
4. 可选：BBS Cubed（`BBS-Cubed-*.jar`）—— 已进一步补充此插件的 POV 中文翻译；
5. 可选：POV（`BBS-POV-*.jar`）—— 本插件翻译补充的目标插件。

## 四、综合：能解什么燃眉之急

### 1. 想追拍演员，但追着追着就想自己动镜头 → 用「多样追踪」

* **燃眉之急**：原版「追踪器」只能静态锁定演员，镜头想脱离追踪手动运镜就得换剪辑，切来切去画面跳变。
* **能干什么**：追踪 + 关键帧二合一。默认 6 位全开 = 纯追踪器；**关掉位掩码里某一位**（X / Y / Z / 偏航 / 俯仰 / 横滚），该轴立刻改由关键帧曲线驱动。
* **怎么用**：添加剪辑 →「多样追踪」→ 选目标演员与部位 → 关掉想手动控制的轴 → 在时间轴打关键帧拖动相机。

### 2. 镜头数值看不懂 / 切剪辑不连贯 → 用 XYZ 双值联动 + 游动/追踪双路线

* **燃眉之急**：关键帧里存的是绝对坐标，改起来要算；不同剪辑衔接时数值体系对不上，画面跳。
* **能干什么**：值面板同时显示相对值（相对绑定模型部位的偏移）与绝对值（地图绝对坐标），改任一个另一个自动换算，永不脱节；主继承按钮随路线自动切换，anchor 未绑定自动走游动、绑定模型自动走追踪，两路线各自独立记忆。
* **怎么用**：选中 X / Y / Z 关键帧 → 直接编辑任一数值即可；新建关键帧默认继承当前路线的值，保证下一帧延续当前数值体系。

### 3. 删光关键帧重来，画面跳回原点 → 空通道自动继承当前视角

* **燃眉之急**：删除全部关键帧后新建帧，通道默认 0，画面瞬间跳回原点 / 角度归零。
* **能干什么**：通道为空时新建关键帧，自动继承预览摄像机当前位置与角度；角度统一归一化到 (-180, 180]；播放头不在任何帧段时回退安全值。
* **怎么用**：删帧后直接打点即可，继承值自动取当前预览视角。

### 4. 追踪目标要在不同演员 / 部位之间切换 → 用「锚点」通道

* **燃眉之急**：剪辑属性只能绑定一个演员，镜头想从模型一的头部平滑移到模型二的脚部，原版做不到。
* **能干什么**：anchor 轴关键帧值 = 追踪目标，相邻关键帧绑不同目标时播放时平滑插值过渡；通道无关键帧时回落到剪辑属性的目标绑定。
* **怎么用**：剪辑「编辑」→ 选中蓝色「锚点」通道 → 打点 → 值面板选演员 + 部位（或吸管点选场景目标）。

### 5. 剪辑太多，右键菜单又长又乱 → 用「可视性设置」

* **燃眉之急**：装上插件后剪辑数量增多，一长竖串占满屏幕，找常用剪辑费劲。
* **能干什么**：右键菜单 1 号位「可视性设置」一键筛选想隐藏 / 想用的剪辑；多列自适应；选「静态」时隐藏剪辑保留原位不重排。
* **怎么用**：编辑器空白处右键 → 第一个「可视性设置」→ 勾选 → 关闭。

### 6. 连建几个关键帧全被选中，操作卡手 → 用「关键帧处理设置」

* **燃眉之急**：一段时间内新建的所有关键帧都会处于被选中状态，选中状态卡手。
* **能干什么**：「关键帧被选中状态」三模式——`[单体]` 新建自动解除上一个的选中；`[混合]` 连续新建只保留最新帧选中、手动选中的帧不受影响。
* **怎么用**：设置 → 摄像机编辑设置 → 关键帧处理设置 → 点选「单体」或「混合」。

### 7. 动画编辑器关键帧轨道要一个个点出来 → 用「关键帧展开模式」

* **燃眉之急**：打开动画编辑器时关键帧轨道默认折叠，需要手动逐个点出所有部件轨道。
* **能干什么**：「关键帧展开模式」选「原始」→ 一次性展开所有部件关键帧轨道。
* **怎么用**：设置 → 摄像机编辑设置 → 关键帧处理设置 → 关键帧展开模式 → 点选「原始」。

### 8. 预新建剪辑菜单又乱又挤 → 用「可视化设置」

* **燃眉之急**：一长竖串的剪辑列表找起来费劲，想要分类收纳。
* **能干什么**：「预创建剪辑可视化」选「覆盖」→ 顶部搜索框 + 三列分类菜单，搜索即时过滤。
* **怎么用**：设置 → 摄像机编辑设置 → 可视化设置 → 点选「覆盖」。

### 9. 忘了某版改过什么 / 想回顾插件履历 → 用「往期日志」

* **燃眉之急**：版本迭代多，想确认某个功能是哪版加的、翻文件费劲。
* **能干什么**：设置页内直接查看完整更新履历，无需离开游戏。
* **怎么用**：设置 → 摄像机编辑设置 → 顶部第一项「往期日志」→ 滚动查看。

### 10. POV 插件的轨道名 / 菜单 / 属性面板全是英文 → POV 中文翻译补充

* **燃眉之急**：装了 POV 插件后，时间轴上的轨道名、右键菜单的 action 类型、属性面板里的 label 文字全是英文。
* **能干什么**：当 Cubed 的「中文关键帧轨道名称」开关打开时，自动翻译 POV 的轨道名、右键菜单 action 类型、属性面板 label（含屏幕特效列表、Boss 血条面板等 400+ 条）；优先用 Cubed 的翻译，只有 Cubed 没覆盖到的才用本插件翻译表。
* **怎么用**：BBS 设置 → Cubed → 打开「中文关键帧轨道名称」开关即可。

> 一句话总结：
>
> **「多样追踪」负责拍得动、锚点通道负责拍得准、双值联动负责衔接顺、空通道继承负责不断线、游动/追踪双路线负责不跳变、可视性设置负责找得快、关键帧处理负责不卡手、分类布局负责不眼乱、POV 翻译负责看得懂、往期日志负责记得住。**
