# BBS 扩展交付包 — Better camera perspective

版本 **v1.1**（2026-10-06）XYZ 关键帧「主继承模式」开关

「Better camera perspective」包含：



1. **新增剪辑「多样追踪」（multi\_tracker）** —— 追踪器 + 关键帧二合一

2. **修复锚点绑定其他演员时显示数据码的 bug** —— 恢复演员显示名

3. **anchor 追踪轴（v0.3）** —— 追踪目标（演员 + 部位）随时间轴关键帧切换，跨演员平滑过渡

4. **XYZ 双值联动编辑（v1.0）** —— 关键帧值面板同时显示「绝对值 + 相对值」，改任一值另一个自动换算，无需再切换模式

5. **锚点绑定列表修复（v1.0.1）** —— 解除「只能看到十余个」的假上限：列表显示影片全部演员（新建 / 未实例化的演员也能选到），并按演员的组 / 类别做**二级选择**（一级 = 类别，二级 = 该类别演员，带返回）

6. **伪装显示名修复（v1.0.1）** —— 修复资产库伪装选择界面中大量模型名称被集体覆盖为同一个演员名的 bug：只在表单实例确实属于影片演员时才反查显示名，资产库里的伪装不再被误改

7. **锚点列表显示名「ID串-类型-伪装名」（v1.0.3）** —— 不强改数据，在原有「ID串 - formId」后面追加可辨识名：自定义名 → 表单名 → 资产库同类型伪装名 → 影片内同类型演员名，都没有时保持原样（如 `071cb8c1 - bbs:model - XY`）。ID 前缀保证条目唯一可区分，名称段负责可辨识；资产库界面不受影响（不回归集体覆盖 bug）

8. **XYZ 关键帧「主继承模式」（v1.1）** —— 关键帧值面板中「相对值 / 绝对值」行首的两个按钮不再是锁死的标签，而是**主继承模式开关**：
   * 默认激活**相对值**（按钮高亮显示「**将主继承相对值**」），此时在时间轴新建关键帧时，新关键帧自动继承**相对值**（相对偏移）；
   * 点击「绝对值」按钮（高亮显示「**将主继承绝对值**」），新建关键帧自动继承**绝对值**（绝对坐标 = 相对偏移 + 该时刻追踪锚点）；
   * 两值仍任改其一、另一个自动同步转换（v1.0 的双值联动不变）；切换模式只影响「下一帧新建关键帧继承哪个值」，不影响当前关键帧与视角状态。

## 三、使用方法

### 1) 多样追踪剪辑



* 打开 BBS 影片编辑器 → 添加剪辑 → 列表中出现 **「多样追踪」**（橙色图标）。

* 面板从上到下：


  * **编辑**：打开 8 通道关键帧编辑器（X / Y / Z / 偏航 / 俯仰 / 横滚 / 视野 / 距离），与「关键帧」剪辑一致；

  * **叠加**：关键帧以叠加（增量）方式生效，同「关键帧」剪辑的 additive；

  * **目标 / 附件**：选择要追踪的演员与骨骼（同「追踪器」）；

  * **偏移 / 角度**：相对追踪点的偏移与视角角度；

  * **看向目标 / 相对**：lookAt 模式 / 相对模式；

  * **启用位掩码**（0-5 共 6 位）：位 0-2 = X/Y/Z 位移跟随，位 3-5 = 偏航 / 俯仰 / 横滚跟随。默认 6 位全开 = 纯追踪器行为；**关掉某一位后，该轴改由关键帧曲线驱动**—— 这就是「多样追踪」的玩法。

* 选中剪辑后拖动相机：先按追踪器方式反解偏移 / 角度，再把相机位置写入关键帧曲线（同「关键帧」剪辑的编辑行为）。

* 视野（fov）不做位掩码，始终由关键帧通道驱动（比原版追踪器更灵活）。

**XYZ 双值联动编辑（v1.0）**：



* 已移除「三向轴模式」通道与 X/Y/Z 的「轴模式」开关，不再需要切换「相对值 / 绝对值」模式。

* 选中 X/Y/Z 通道的关键帧时，值面板**同时显示两个数值**：**（核心改动）**


  * **相对值**：该视角相对于被绑定模型及部位（或默认位置）的相对偏移 —— 编辑此值直接改变关键帧；

  * **绝对值**：该视角在地图上的绝对坐标 —— 编辑此值也会自动换算并写入关键帧。

* 两个值**任改其一，另一个值自动同步转换**（绝对 = 相对 + 该时刻追踪锚点），数值始终一致、画面不跳变。

* 播放时 XYZ 关键帧按「相对值」语义生效（锚点 + 偏移合成）；不设追踪目标时相对值 = 绝对值。

**XYZ 关键帧「主继承模式」（v1.1）**：



* 「相对值」「绝对值」两个行首按钮从锁死标签升级为可点击的**主继承模式开关**：


  * **默认激活「相对值」**：按钮高亮显示「**将主继承相对值**」—— 之后在时间轴**新建关键帧**（打点 / 自动记录），新关键帧自动继承**相对值**（相对偏移）；
  * 点击「绝对值」按钮：高亮显示「**将主继承绝对值**」—— 新建关键帧自动继承**绝对值**（绝对坐标）；
  * 切换只影响后续新建关键帧的**继承值**，当前关键帧与视角不受影响；相对 / 绝对两值的联动换算保持不变。

### 1b) anchor 追踪轴（v0.3）



* 多样追踪关键帧编辑器在 X/Y/Z/ 偏航 / 俯仰 / 横滚 / 视野 / 距离 之外，新增 **「锚点」** 通道（蓝色）。

* 「锚点」通道的关键帧值 = **追踪目标**（演员 + 模型部位），原理同模型数据的 anchor 轴：


  * **通道无关键帧**（或关键帧为空值）→ 追踪目标使用剪辑属性的 **目标 / 附件** 绑定（与旧版行为一致）；

  * **通道有关键帧且值非空** → 该时刻追踪目标以 **anchor 轴数值为主**（覆盖剪辑属性绑定）；

  * **相邻关键帧绑定不同目标**（如 1tick 绑模型一头部、20tick 绑模型二脚部）→ 播放时在两个目标的追踪结果之间**平滑插值过渡**，避免画面跳变。

* 编辑方式：进入剪辑「编辑」→ 选中「锚点」通道 → 点击时间轴打点 → 在关键帧值面板选**演员**与**部位**（或使用吸管直接点选场景中的演员 / 部位），与 BBS 模型动画的锚点编辑一致。

* 与 XYZ 双值编辑独立：anchor 轴只决定**追踪目标**，XYZ 关键帧的「绝对值 / 相对值」由值面板双值联动自动换算，互不影响。

### 2) 锚点显示修复



* 进入某个演员 / 模型的表单编辑器 → 属性面板「锚点」→ 选择绑定到其他演员时，列表显示该演员的**名称**（如 `GM-L`），不再显示 `071cb8c1 - bbs:model` 这类数据码。

* 原理：锚点数据里存的是演员的稳定 ID，修复后会在当前打开的影片中反查回该演员的自定义名称。

* **v1.0.1 修正**：此前「按表单类型匹配」的兜底会误伤**资产库伪装**—— 资产库伪装与影片演员使用同一伪装模板时类型相同，显示名会被集体覆盖成影片里某个演员的名字（伪装选择界面大量模型显示同一内容）。现改为**仅引用相等反查**（表单实例确实挂在影片演员上才反查），资产库伪装恢复正常，影片演员名称不受影响。

* **v1.0.3 修正**：改为「屎山叠屎山」方案 —— 不强改数据，直接在原「ID串 - formId」后追加可辨识名（`071cb8c1 - bbs:model - XY` 样式）。名称来源按优先级：自定义名（label）→ 表单名（form.name）→ 资产库同类型伪装名（仅列表内部反查，资产库界面不受影响）→ 影片内同类型演员名；都没有时保持「ID串 - formId」不变。ID 前缀始终保证条目唯一可区分。

### 3) 锚点绑定列表（v1.0.1）



* 锚点「选择角色」列表不再受实体实例化状态过滤：影片中**新建、尚未实例化的演员也能被选中**（此前看不到，误以为是 11 个上限）。

* 列表按演员的**组 / 类别**做二级选择：一级 = 类别（含「未分类」），二级 = 该类别下全部演员（带「返回」）；只有一个类别时直接平铺。

* 菜单可滚动，演员条目 ≥12 个时自动出现搜索过滤框，不再受屏幕高度截断。
