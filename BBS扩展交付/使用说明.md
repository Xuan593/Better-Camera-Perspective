# BBS 扩展 — Better camera perspective 使用说明

版本 **V1.4.1**（2026-10-09）

面向 BBS FS 影片编辑器的摄像机增强插件：新增「多样追踪」剪辑（追踪 + 关键帧二合一、相对 / 绝对双值联动）、anchor 追踪轴平滑切换、锚点绑定列表修复，以及剪辑可见性筛选。

个人插件（语雀）：https://www.yuque.com/huangyingxuanyan/krkn1x/gugz9cdalyvuo7d3?singleDoc# 《Better camera perspective》

---

## 一、核心功能

### 1. 「多样追踪」剪辑（v0.1 起）—— 追踪器 + 关键帧二合一

新增剪辑「多样追踪」（橙色图标），在原有「追踪器」剪辑（仅静态追踪演员，相当于有追踪能力的「静止」剪辑）基础上，叠加完整的关键帧编辑能力，相当于**有追踪能力的「关键帧」剪辑**。

剪辑面板从上到下：

| 选项 | 说明 |
| --- | --- |
| **编辑** | 打开关键帧编辑器（X / Y / Z / 偏航 / 俯仰 / 横滚 / 视野 / 距离 / 锚点），操作方式与「关键帧」剪辑一致 |
| **叠加** | 关键帧以叠加（增量）方式生效，同「关键帧」剪辑的 additive |
| **目标 / 附件** | 选择要追踪的演员与骨骼部位（同「追踪器」） |
| **偏移 / 角度** | 相对追踪点的偏移与视角角度 |
| **看向目标 / 相对** | lookAt 模式 / 相对模式 |
| **启用位掩码**（0–5 共 6 位） | 位 0–2 = X/Y/Z 位移跟随；位 3–5 = 偏航 / 俯仰 / 横滚跟随。默认 6 位全开 = 纯追踪器行为；**关掉某一位后，该轴改由关键帧曲线驱动**—— 这就是「多样追踪」的核心玩法 |

* 选中剪辑后拖动相机：先按追踪器方式反解偏移 / 角度，再把相机位置写入关键帧曲线（同「关键帧」剪辑的编辑行为）。
* 视野（fov）不做位掩码，始终由关键帧通道驱动（比原版追踪器更灵活）。

### 2. XYZ 双值联动编辑（v1.0 起）

选中 X/Y/Z 通道的关键帧时，值面板**同时显示两个数值**，无需再切换「相对值 / 绝对值」模式：

* **相对值**：该视角相对于被绑定模型及部位（或默认位置）的相对偏移；
* **绝对值**：该视角在地图上的绝对坐标。

两个值**任改其一，另一个自动同步转换**（绝对 = 相对 + 该时刻追踪锚点），数值始终一致、画面不跳变。播放时 XYZ 关键帧按相对值语义生效（锚点 + 偏移合成）；不设追踪目标时相对值 = 绝对值。

### 3. XYZ 关键帧「主继承模式」（v1.1 起）

「相对值」「绝对值」两个行首按钮是可点击的**主继承模式开关**：

* **默认激活「相对值」**：按钮显示「将主继承相对值」—— 之后在时间轴**新建关键帧**时自动继承**相对值**（相对偏移）；
* 点击「绝对值」按钮：显示「将主继承绝对值」—— 新建关键帧自动继承**绝对值**（绝对坐标）；
* 切换只影响后续新建关键帧的**继承值**，当前关键帧与视角状态不受影响；相对 / 绝对两值的联动换算保持不变。

> **V1.4.1 语义修正**：通道值恒为「相对偏移」——相对模式下新帧显示相对值；绝对模式下新帧显示 = 相对值 + 锚点 = 摄像机当前位置。修复了此前绝对模式继承把锚点重复加一次（双倍锚点）导致画面跳变的问题。

### 4. 删除所有帧后新建关键帧，继承摄像机默认视角（V1.4.1 起）

* **此前**：删除全部关键帧后重新新建帧，X / Y / Z / 偏航 / 俯仰 / 横滚 / 视野帧属性默认为 `0`，画面瞬间跳回原点 / 角度归零。
* **现在**：通道为空时新建关键帧，自动继承**摄像机当前默认视角**：
  * X / Y / Z → 预览摄像机位置 − 追踪锚点 = 相对偏移（不跳变）；
  * 偏航 / 俯仰 / 横滚 / 视野 → 预览摄像机当前角度与视野值。
* 该逻辑同时作用于关键帧编辑界面的时间轴打点与编辑器「新建帧」按钮（seed 继承）。

### 5. anchor 追踪轴（v0.3 起）

多样追踪关键帧编辑器在 8 通道之外，新增 **「锚点」** 通道（蓝色）。锚点通道的关键帧值 = **追踪目标**（演员 + 模型部位），原理同模型数据的 anchor 轴：

* **通道无关键帧**（或关键帧为空值）→ 追踪目标使用剪辑属性的「目标 / 附件」绑定（与旧版行为一致）；
* **通道有关键帧且值非空** → 该时刻追踪目标以 **anchor 轴数值为主**（覆盖剪辑属性绑定）；
* **相邻关键帧绑定不同目标**（如 1tick 绑模型一头部、20tick 绑模型二脚部）→ 播放时在两个目标的追踪结果之间**平滑插值过渡**，避免画面跳变。

编辑方式：进入剪辑「编辑」→ 选中「锚点」通道 → 时间轴打点 → 在关键帧值面板选**演员**与**部位**（或吸管直接点选场景中的演员 / 部位）。anchor 轴只决定追踪目标，与 XYZ 双值编辑相互独立。

> **V1.4.1 跨 tick 读取修正**：anchor 关键帧与 XYZ 关键帧通常不在同一 tick 新建——tick 处 anchor 插值读不到目标时，自动**回退读取 tick 之前最近的非空 anchor 关键帧**，锚点坐标始终被正确读到（配合锚点绑定后的 XYZ 归零，摄像机贴回锚点，不再被旧相对偏移甩远）。
>
> **V1.4.1 已知问题**：锚点绑定目标后 XYZ 相对值**自动归零暂未生效**，需要手动将三轴相对值归零后继续追踪（修复中）。

### 6. 锚点显示修复（v0.1 / v1.0.1 / v1.0.3）

* **恢复演员显示名**：进入演员 / 模型的表单编辑器 → 属性面板「锚点」→ 绑定其他演员时，列表显示该演员名称（如 `GM-L`），不再显示 `071cb8c1 - bbs:model` 这类数据码。
* **v1.0.1 修正**：改为仅引用相等反查（表单实例确实挂在影片演员上才反查显示名），资产库伪装不再被误改，伪装选择界面恢复正常。
* **v1.0.3 方案（保留）**：「ID 串 - 类型 - 伪装名」命名 —— 不强改数据，在原「ID 串 - formId」后追加可辨识名（如 `071cb8c1 - bbs:model - XY`）。名称来源优先级：自定义名 → 表单名 → 资产库同类型伪装名 → 影片内同类型演员名；都没有时保持「ID 串 - formId」不变。ID 前缀保证条目唯一可区分。

### 7. 锚点绑定列表（v1.0.1 起）

* 解除「只能看到十余个」的假上限：列表显示影片**全部**演员，新建 / 未实例化的演员也能被选中；
* 按演员的**组 / 类别**做二级选择：一级 = 类别（含「未分类」），二级 = 该类别下全部演员（带「返回」）；只有一个类别时直接平铺；
* 菜单可滚动，演员条目 ≥ 12 个时自动出现搜索过滤框。

### 8. 剪辑可见性筛选「可视性设置」（v1.2 系列起）

* **入口**：摄像机编辑器右键菜单 **1 号位**「可视性设置」（视觉上与其他剪辑项融为一体，位于「静止」上方）；
* **行为**：自由勾选想隐藏 / 想派上用场的剪辑；每次筛选后菜单**自动重新排列**；
* **多列自适应**：一列上限 10 个剪辑，超出部分放入下一列，列数上限 5（不算「可视性设置」，理论可容纳 49 个剪辑）；
* **持久化**：退出 BBS 页面时读取并存储当前可视性设置，**恢复全开**（避免缺少本插件时直接崩溃）。

> **V1.4.0-BETA 起**：该功能源码已交付 BBS Cubed 作者「一阵泠风」，由 Cubed 合并同类功能；本插件保留自身实现。

### 9. 「剪辑处理设置」（v1.3.2 起，v1.3.3 已移除）

该分类（调整剪辑可见性 / 剪辑名称显示 / 剪辑边界线 / 剪辑类型配色 4 个开关）经实测判定为无用内容，自 **v1.3.3** 起整体剔除，剪辑条显示恢复 BBS 原版默认行为（名称、边界线、类型配色正常显示，无整理过渡动画）。

### 10. 同功能多 Mod 冲突预防（v1.3.1 起，V1.4.0-BETA 已移除）

* v1.3.1 曾提供「冲突功能」设置页与进入编辑器弹窗，用于同一功能存在多个 Mod 来源（如与 BBS Cubed 的剪辑可见性筛选）时逐功能选择模式。
* **V1.4.0-BETA 起已整体移除**（删除 BcpConflictManager / ChoiceRow / OverlayPanel / UISettingsLayoutMixin）：功能已由 Cubed 合并，无需再预防冲突。

## 三、安装

1. 环境：Minecraft **1.20.1（Fabric）** + **Fabric API**；
2. 将 `better-camera-perspective-V1.4.1.jar` 放入 `.minecraft/mods`；
3. 确保 **BBS FS 2.7**（`bbs-2.7-1.20.1-zh_CN.jar`）在 mods 中；
4. 可选：BBS Cubed 3.5.2（其剪辑可见性筛选与本插件同功能，由 Cubed 侧合并协调）。

## 四、综合：能解什么燃眉之急

以下按实际拍摄 / 剪辑中会遇到的痛点，说明当前版本（V1.4.1）对应功能**干什么、怎么用**：

### 1. 想追拍演员，但追着追着就想自己动镜头 → 用「多样追踪」

* **燃眉之急**：原版「追踪器」只能静态锁定演员，镜头想脱离追踪手动运镜就得换剪辑，切来切去画面跳变。
* **能干什么**：追踪 + 关键帧二合一。默认 6 位全开 = 纯追踪器；**关掉位掩码里某一位**（X / Y / Z / 偏航 / 俯仰 / 横滚），该轴立刻改由关键帧曲线驱动。
* **怎么用**：添加剪辑 →「多样追踪」→ 选目标演员与部位 → 关掉想手动控制的轴 → 在时间轴打关键帧拖动相机。

### 2. 镜头数值看不懂 / 切剪辑不连贯 → 用 XYZ 双值联动 + 主继承模式**（个人认为最强的更新）**

* **燃眉之急**：关键帧里存的是绝对坐标，改起来要算；不同剪辑衔接时数值体系对不上，画面跳。
* **能干什么**：值面板同时显示**相对值**（相对绑定模型部位的偏移）与**绝对值**（地图绝对坐标），改任一个另一个自动换算，永不脱节。
* **怎么用**：选中 X / Y / Z 关键帧 → 直接编辑任一数值即可；新建关键帧默认继承相对值（点「将主继承绝对值」可切换），保证下一帧延续当前数值体系，衔接自然。

### 3. 删光关键帧重来，画面却跳回原点 / 角度归零 → V1.4.1 已修复

* **燃眉之急**：删除全部关键帧后新建帧，X / Y / Z / 偏航 / 俯仰 / 横滚 / 视野默认 `0`，画面瞬间跳回原点 / 归零。
* **能干什么**：通道为空时新建关键帧，自动继承**摄像机当前默认视角**（位置与角度），新建帧后画面不跳变、衔接自然。
* **怎么用**：删帧后直接打点即可，继承值自动取当前预览视角。

### 4. 追踪目标要在不同演员 / 部位之间切换 → 用「锚点」通道

* **燃眉之急**：剪辑属性只能绑定一个演员，镜头想从模型一的头部平滑移到模型二的脚部，原版做不到。
* **能干什么**：anchor 轴关键帧值 = 追踪目标，1tick 绑模型一头部、20tick 绑模型二脚部，播放时两目标之间**平滑插值过渡**；通道无关键帧时自动回落到剪辑属性的目标绑定。V1.4.1 起跨 tick 也能正确读取锚点。
* **怎么用**：剪辑「编辑」→ 选中蓝色「锚点」通道 → 打点 → 值面板选演员 + 部位（或吸管点选场景目标）。

> **已知问题（V1.4.1）**：锚点绑定目标后 XYZ 相对值**自动归零暂未生效**，需手动将三轴相对值归零后继续追踪（修复中）。


### 5. 剪辑太多，右键菜单又长又乱 → 用「可视性设置」

* **燃眉之急**：装上插件后剪辑数量增多，一长竖串占满屏幕，找常用剪辑费劲。
* **能干什么**：右键菜单 **1 号位**「可视性设置」一键筛选想隐藏 / 想用的剪辑；筛选后菜单**自动重排**，多列自适应（一列上限 10、列数上限 5，理论容纳 49 个剪辑）；退出 BBS 页面自动存储并**恢复全开**，防崩溃。
* **怎么用**：编辑器空白处右键 → 第一个「可视性设置」→ 勾选 → 关闭，菜单立即按筛选重排。

> 一句话总结：
>
> **「多样追踪」负责拍得动、锚点通道负责拍得准、双值联动负责衔接顺、新建帧继承负责不断线、可视性设置负责找得快。**
