# BBS 扩展交付包 — Better camera perspective

版本 **Alpha-0.2**（2026-10-04）

基于你的 Fabric 模组工程「Better camera perspective」实现的 BBS FS 附加包，包含：

1. **新增剪辑「多样追踪」（multi_tracker）** —— 追踪器 + 关键帧二合一
2. **修复锚点绑定其他演员时显示数据码的 bug** —— 恢复演员显示名
3. **新增「轴数值模式」开关（v0.2）** —— XYZ 关键帧在「相对值 / 绝对值」间切换，数值可相互转换

---

## 一、文件说明

| 文件 | 用途 |
|---|---|
| `better-camera-perspective-Alpha-0.2.jar` | **成品模组 v0.2**（可直接放入 `.minecraft/mods`） |
| `better-camera-perspective-0.1-Alpha.jar` | 旧版 v0.1 成品（备份，可删除） |
| `bbs-2.7-1.20.1.jar` | BBS FS 主模组 2.7（重新打包自 Addon 解压目录，格式校验通过；如你已有原版 jar 可二选一） |

> 注：`src\` 中有少量平铺的重复副本（与包路径下的正式文件内容一致），不影响任何使用。

## 二、安装

1. 把 `better-camera-perspective-Alpha-0.2.jar` 放进 `.minecraft/mods`（Fabric 1.20.1，需要 fabric-api）。
2. 确保 BBS FS 2.7 在 mods 中（本包附带的 `bbs-2.7-1.20.1.jar` 可直接使用）。
3. 启动游戏。日志出现以下三行即注册成功：
   - `[BCP] 多样追踪剪辑 (MultiTrackerClip) 服务端注册成功`
   - `[BCP] 多样追踪客户端剪辑类 (MultiTrackerClientClip) 注册成功`
   - `[BCP] 多样追踪 UI 面板 (UIMultiTrackerClip) 注册成功`

## 三、使用方法

### 1) 多样追踪剪辑
- 打开 BBS 影片编辑器 → 添加剪辑 → 列表中出现 **「多样追踪」**（橙色图标）。
- 面板从上到下：
  - **编辑**：打开 8 通道关键帧编辑器（X / Y / Z / 偏航 / 俯仰 / 横滚 / 视野 / 距离），与「关键帧」剪辑一致；
  - **叠加**：关键帧以叠加（增量）方式生效，同「关键帧」剪辑的 additive；
  - **目标 / 附件**：选择要追踪的演员与骨骼（同「追踪器」）；
  - **偏移 / 角度**：相对追踪点的偏移与视角角度；
  - **看向目标 / 相对**：lookAt 模式 / 相对模式；
  - **启用位掩码**（0-5 共 6 位）：位 0-2 = X/Y/Z 位移跟随，位 3-5 = 偏航/俯仰/横滚跟随。默认 6 位全开 = 纯追踪器行为；**关掉某一位后，该轴改由关键帧曲线驱动**——这就是「多样追踪」的玩法。
  - **轴数值模式**（v0.2）：循环按钮，默认 **相对值**；点击切换为 **绝对值**。
- 选中剪辑后拖动相机：先按追踪器方式反解偏移/角度，再把相机位置写入关键帧曲线（同「关键帧」剪辑的编辑行为）。
- 视野（fov）不做位掩码，始终由关键帧通道驱动（比原版追踪器更灵活）。

**轴数值模式（XYZ 关键帧取值方式，v0.2）**：
- **相对值**（默认）：设置追踪目标后，XYZ 关键帧 = **相对锚点的偏移**（「偏移」栏语义），播放时摄像机 = 锚点位置 + XYZ 关键帧偏移——摄像机与演员保持相对关系，切换/衔接其他剪辑时更自然；未打 XYZ 关键帧时摄像机锁定在锚点（纯追踪器行为）。
- **绝对值**：XYZ 关键帧 = 世界坐标绝对值，与「关键帧」剪辑完全一致（无追踪基准）。
- **切换不影响摄像机视角状态本身**：切换时会把已有关键帧数值在两种语义间**逐帧换算**（相对 ↔ 绝对 = ± 该时刻锚点位置），画面不跳变。
- 偏航/俯仰/横滚/视野/距离两种模式下都保持「关键帧」剪辑的绝对值语义。
- 不设追踪目标时，相对值模式退化为绝对值（等同「关键帧」剪辑）。

### 2) 锚点显示修复
- 进入某个演员/模型的表单编辑器 → 属性面板「锚点」→ 选择绑定到其他演员时，列表显示该演员的**名称**（如 `GM-L`），不再显示 `071cb8c1 - bbs:model` 这类数据码。
- 原理：锚点数据里存的是演员的稳定 ID，修复后会在当前打开的影片中反查回该演员的自定义名称。
- **v2 加固**：① 影片重新加载导致表单实例变化时，按表单类型匹配仍能反查；② 表单名称字段被写成稳定 ID（8 位 hex）时同样反查，不再显示数据码。

## 四、重新构建（改代码后）

```
gradle build --no-daemon
```
- Gradle 用户目录已指向 D 盘（`GRADLE_USER_HOME`），依赖走阿里云镜像（`init.gradle`）。
- BBS 依赖为本地 jar（`libs\bbs-2.7-1.20.1.jar`），Loom 自动 remap。
- 产物在 `build/libs/better-camera-perspective-Alpha-0.2.jar`（版本号在 `gradle.properties` 的 `mod_version`）。
