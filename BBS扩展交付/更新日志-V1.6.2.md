### 新增：关键帧展开模式（设置 - 摄像机编辑设置 - 关键帧处理设置）

**背景**：BBS 2.7 更新后，动画编辑器（动画状态编辑器）打开 / 切换部件时，所有部件关键帧轨道默认折叠，不再像旧版那样一次性全部展开，需要手动逐个点出，非常麻烦。

- 在「关键帧处理设置」分类下（「关键帧被选中状态」按钮组下方）新增设置项 **关键帧展开模式**，两个单选按钮，选中即应用：
  - **默认**：BBS 2.7 现状 —— 关键帧轨道折叠，需手动逐个点出展开；
  - **原始**：一次性展开**所有**部件关键帧轨道，恢复旧版（2.7 之前）行为；
- **可视度筛选联动**：被可视度筛选排除的轨道不会进入编辑器轨道列表，「原始」模式不会把它们展开（只展开可见轨道），避免误伤被隐藏的内容；
- **独立设置值**：与「关键帧被选中状态」等既有设置分开存储、互不影响；「默认」模式下完全不干预 BBS 原逻辑，不影响其他正常功能。

### 实现要点（不侵入原逻辑）

- 设置值沿用既有 `BcpModeValue`（单选值）+ `BcpModeValueUi`（说明文本 + 并列按钮，选中黄色高亮）通用链路，新增 key 为 `keyframe_expand`（`default` / `original`），默认 `default`；
- 新增 mixin `UIAnimationStateEditorMixin`：仅在「原始」模式命中时，于 `UIAnimationStateEditor.setState` 完成后把 `expandedTabs` 中全部 sheet / section 设为展开；「默认」模式不注入任何行为；
- 展开对象为 dope sheet 中实际加载的轨道列表（含父级部件与子级轨道），折叠状态与该编辑器共享同一 `FoldState`，立即生效且可被用户手动折叠单条轨道。

### 修订：修复首次交付的 mixin 注入签名错误（启动崩溃）

首次交付的 `UIAnimationStateEditorMixin` 中 `@Inject` handler 误把 `this`（`UIAnimationStateEditor`）写为第一个参数，与目标方法 `setState(AnimationState)` 的实际签名不符，mixin 应用阶段报 `InvalidInjectionException`（期望 `(AnimationState, CallbackInfo)`），客户端在进入 BBS 面板时崩溃。已修正 handler 签名（首参改为 `AnimationState state`），重新构建交付；**与 Cubed 无冲突，与「关键帧展开模式」默认值无关**。

### 二轮修订：展开方式改为「整体替换折叠状态」（修复实测未生效）

签名修复后实测：设置页「原始」可正常选中，但打开动画编辑器后轨道仍逐条手动点出，注入未产生一次性展开效果。排查后确认 BBS 2.7 折叠判定分两级（轨道自身 `section.id()` + 父级 `sheet.id` 的 `isUnfolded`），且 `expandedTabs.set` 只改状态、渲染按帧重读 `folds`——单靠逐条 set 存在 key / 时机覆盖不全的可能。本版改为：

- 「原始」命中时，将 dope sheet 的折叠状态整体替换为「默认全展开」`FoldState`（`defaultExpanded=true`），**所有当前与之后添加的部件关键帧轨道一次性全部展开**，且用户仍可手动折叠单条轨道（toggle 新折叠状态立即生效）；
- 同时保留逐 sheet 显式展开兜底（自身 `section` + `id` 双 key）；
- 增加运行日志（`[BCP] expand: ...`），若仍有异常可凭 `latest.log` 定位；
- 「默认」模式依旧零干预；可视度筛选排除的轨道不进入轨道列表，天然不会被展开。

### 三修：注入目标改为「回放编辑器 UIReplaysEditor」（前两版注入错类，从未执行）

二修实测仍未生效，`latest.log` 无任何 `[BCP] expand` 输出，且确认用户 mods 目录已装二修 jar——结合录屏重新取证：**用户实际打开的是影片面板（UIFilmPanel）里的「回放编辑器 UIReplaysEditor」**（编辑 Replay 关键帧轨道，含姿势/姿势叠加/位移/锚点/身体部件轨道），此前注入的 `UIAnimationStateEditor` 是动画面板中的编辑器，用户并不打开，故注入从未执行。

- 反编译确认 2.7 折叠根源：`UIReplaysEditor.getExpandedTracks()` 为每个回放创建折叠状态时，仅默认展开 `replay_section/position_rotation` 一个 section，其余部件关键帧轨道全部折叠、需手动逐个点出；
- 新增 mixin `UIReplaysEditorMixin`：注入 `updateChannelsList`（打开回放 / 切换分类 / 切换部件 / 全部轨道等所有重建路径的统一入口）RETURN，在「原始」命中时把当前回放的展开状态（`getExpandedTracks()`，与 dope sheet 折叠状态为同一对象）中全部 sheet / section 设为展开；
- 展开状态写入 `expandedTracksByReplay`（按回放记忆），切换回放再回来仍保持展开；用户仍可手动折叠单条轨道；
- 保留 `UIAnimationStateEditorMixin`（动画状态编辑器同样覆盖）；「默认」模式依旧零干预，可视度筛选排除的轨道天然不被展开。
