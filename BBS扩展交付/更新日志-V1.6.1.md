### 转正说明：V1.6.1-Alpha 整合后成功的核心内容

**核心功能：多样追踪新增关键帧轴「相位追踪」（单独类属性，默认关）**

- 在「多样追踪」剪辑中新增一条关键帧轴 **相位追踪**（值面板：开关 + 跟随强度），每帧独立开关；
- **关（默认）/ 开**：开启时，读取当前摄像机的跟踪模式与相对 / 绝对坐标（即关键帧驱动的最终机位），以及被追踪演员（伪装）的相关坐标，自动把摄像机朝向平滑转向演员，实现**非完全锁定式的自动效果跟踪**——摄像机位置不被修改（仍由关键帧曲线 / 游动 / 追踪驱动），只有朝向（偏航 / 俯仰）被接管，尽可能减少视角之间的不平滑；
- **被追踪演员取法**：与追踪路线一致 —— anchor 轴当前关键帧绑定谁就盯谁；无绑定（`<无>` / 无 anchor 帧）回退剪辑属性「追踪目标 - 选取目标…」；
- **两种典型拍摄**：① 演员移动、机位不动 —— 摄像机在不跟随移动的状态下持续转头盯住演员；② 演员机位同动 —— 摄像机在被移动的过程中时刻追踪演员，丝滑视角录制；
- **跟随强度（0~1，默认 0.9）**：1 = 完全盯住演员；0 = 保持关键帧朝向（等同关闭）；调低可获得更柔和的部分跟随；
- **不干预项**：摄像机位置、横滚（roll）、视野（fov）均不参与相位追踪；目标解析失败 / 开关关闭 / 无关键帧时完全不干预画面。

**实现要点（单独类属性，避免污染）**

- 新增帧级数据类 `PhaseFrameData`（开关 + 跟随强度）与 `PhaseFrameDataKeyframeFactory`（类型名 `bcp_phase_frame`），**与 xd/yd/zd 的 `XyzFrameData` 完全分离存储**，每帧独立，不共用数值池，杜绝游动 / 追踪 / 相位之间的相互污染；
- 新通道 `phase` 已加入服务端 / 客户端剪辑注册表，工厂在启动时注册进 BBS 全局 `KeyframeFactories`（类型名稳定，旧存档可正常读回）；
- 播放端在关键帧求值（游动 / 追踪世界坐标）之后接入：以**最终机位**为参考解析演员相对方向，按 BBS 原生 lookAt 同口径计算朝向，再以「最短弧 + 跟随强度」插值，避免开关切换瞬间的突兀跳变；
- 时间轴新增「相位追踪」行（亮紫标识），选中关键帧可编辑开关与跟随强度；新建关键帧默认「关」。

### 修订①：修复「相位追踪」与锚点（anchor）关键帧冲突（转向几乎不生效）

实测发现：锚点绑定具体伪装后，相位追踪虽已开启，但相机始终不转向演员（演员一直停在画面边缘）。定位为**角度单位错误**，与锚点追踪逻辑无关：

- BBS 的 yaw/pitch/roll 通道与 `Angle.angle` 计算结果均为**角度制（度）**；而角度最短弧插值误把「度」直接当作「弧度」传给 `sin/cos`，导致跟随强度 0.9 时每帧只转约 1~2°（本应转约 81°），相机被锚点追踪角度锁死、看起来「与锚点冲突」；
- 已修正为「度 → 弧度取最短弧 → 转回度」。同一公式也用于**游动 ⇄ 追踪过渡**与**跨演员（伪装）过渡**的角度混合，此前这两处的大角度差过渡同样存在转向不足，一并修正；
- 行为边界：**相位追踪关闭（默认）时完全不介入角度**，锚点追踪 / 游动 / 关键帧的既有行为逐帧保持不变；仅在开关为「开」时才按跟随强度接管偏航 / 俯仰。

### 修订②：相位追踪面板优化（数值范围 + 布局）

- **跟随强度数值范围限制为 0~1**：此前数值框无范围限制，可输入 -3.85 之类越界值（播放端虽会强制收敛，但界面易误导）；现输入框直接限制 0~1；
- **UI 布局优化（两轮）**：面板由「标题 / 开关按钮 / 强度行」三行松散排布，先改为「标题 + 单行三元素」紧凑排布，再进一步改为**两行对齐式** —— 每行为「固定宽度标签 + 控件」（`开关 [开/关]` / `跟随强度 [0.9]`），标签同宽、控件对齐，与 XYZ 值面板（游动 / 追踪）的行式风格统一，消除拥挤与错位。
