# 更新日志 - better-camera-perspective-v1.4.1

> 排序：最新 → 最初

## v1.4.1（当前版本）

**修复**

1. **多样追踪 · 删除所有帧后新建关键帧不再默认为 0**
   - 此前：删除全部关键帧后重新新建帧，X / Y / Z 帧属性默认为 `0`，画面瞬间跳回坐标原点。
   - 现在：通道为空时新建关键帧，自动继承**摄像机当前默认视角**（预览摄像机位置 − 锚点 = 相对偏移），新建帧后画面不跳变、衔接自然。
   - 该逻辑同时作用于关键帧编辑界面的时间轴打点与 X / Y / Z 双值编辑器的「新建帧」按钮（seed 继承）。

2. **多样追踪 · 锚点绑定目标后 X / Y / Z 相对值自动归零**
   - 此前：在 anchor 选中模型/部位后，X / Y / Z 三轴的相对值保留旧的非零数值，摄像机 = 新锚点 + 旧相对偏移，被偏移到较远位置，需手动归零才能继续追踪。
   - 现在：无论通过**属性面板「选取目标 / 选择附件」**还是 **anchor 轴关键帧编辑**选择锚点目标，选定后多样追踪的 X / Y / Z 相对值通道全部自动归零，摄像机立即贴回锚点，可直接进行下一步追踪操作。

**修正（承 v1.1）**

3. **主继承绝对值的数值语义修正**
   - 通道值恒为「相对偏移」：相对模式下新帧显示相对值；绝对模式下新帧显示 = 相对值 + 锚点 = 摄像机当前位置。
   - 修复了此前绝对模式继承会把锚点重复加一次（双倍锚点）导致画面跳变的问题。
