# 更新日志 - better-camera-perspective-V1.4.1

> 排序：最新 → 最旧

## V1.4.1（半成品更新）

### 第 3 次修订（最新）・锚点部位解析失败回退模型根



* 锚点部位（group）路径解析失败时，回退到模型根骨骼再取坐标，保证锚点能读到（摄像机不再被旧相对偏移甩远）。

* 防御性修复：配合第 2 次修订的跨 tick 回退，双保险兜底。

### 第 2 次修订・偏航 / 俯仰 / 横滚 / 视野继承扩展 + 锚点跨 tick 读取修正



1. **多样追踪・删除所有帧后新建关键帧不再默认为 0（含偏航［这个救不了］ / 俯仰 / 横滚 / 视野）**

* 此前：删除全部关键帧后重新新建帧，X / Y / Z / 偏航 / 俯仰 / 横滚 / 视野帧属性默认为 `0`，画面瞬间跳回原点 / 角度归零。

* 现在：通道为空时新建关键帧，自动继承**摄像机当前默认视角**：


  * X / Y / Z → 预览摄像机位置 − 追踪锚点 = 相对偏移（不跳变）；

  * 偏航 / 俯仰 / 横滚 / 视野 → 预览摄像机当前角度与视野值。

* 该逻辑同时作用于关键帧编辑界面的时间轴打点与编辑器「新建帧」按钮（seed 继承）。

1. **多样追踪・锚点跨 tick 读取修正（解决「anchor 选中模型后摄像机被甩远」）**

* 根因：anchor 关键帧与 XYZ 关键帧通常不在同一 tick 新建；tick 处 anchor 插值读不到目标时锚点按 0 处理，XYZ 继承值 = 摄像机位置（非相对偏移），摄像机 = 锚点 + 旧大偏移 → 被甩远。

* 现在：tick 处 anchor 无目标时，回退读取 **tick 之前最近的非空 anchor 关键帧**，锚点坐标被正确读到；配合选中目标后的 XYZ 自动归零，摄像机贴回锚点。

### 首版・XYZ 新建帧继承 + 锚点绑定归零 + 绝对继承语义修正



1. **多样追踪・删除所有帧后新建 XYZ 关键帧继承默认视角（不再默认为 0）**

* 此前：删除全部关键帧后重新新建帧，X / Y / Z 帧属性默认为 `0`，画面瞬间跳回坐标原点。

* 现在：通道为空时新建关键帧，自动继承**摄像机当前默认视角**（预览摄像机位置 − 锚点 = 相对偏移），新建帧后画面不跳变、衔接自然。

* 该逻辑同时作用于关键帧编辑界面的时间轴打点与编辑器「新建帧」按钮（seed 继承）。

1. **多样追踪・锚点绑定目标后 X / Y / Z 相对值自动归零**

* 无论通过 \*\* 属性面板「选取目标 / 选择附件」\*\* 还是 **anchor 轴关键帧编辑**选择锚点目标，选定后多样追踪的 X / Y / Z 相对值通道全部自动归零，摄像机立即贴回锚点，可直接进行下一步追踪操作。【修复失败，需要手动将相对值归零】

1. **主继承绝对值的数值语义修正（承 v1.1）**

* 通道值恒为「相对偏移」：相对模式下新帧显示相对值；绝对模式下新帧显示 = 相对值 + 锚点 = 摄像机当前位置。

* 修复了此前绝对模式继承会把锚点重复加一次（双倍锚点）导致画面跳变的问题。
