## V1.7.1（2026-10-31）【正式版・功能冲突检测设置页】

V1.7 之后新增的冲突检测功能转正，让用户可手动选择翻译优先级，适配 Cubed 3.6.3 hotfix 已大幅完善中文翻译的现状。

**UI 小修复**：去除按钮文本两侧方括号 `[ ]`，按钮宽度拉长 50%（58→87px），文本居中对齐不变。

### 核心功能：功能冲突检测设置页

设置页左侧导航 2 号位（1号位往期日志之后）新增「功能冲突检测」子页：

- **自动检测来源数量**：按功能独立统计来源数（BCP=1，检测到其他插件+1），来源数 ≥ 2 才显示对应按钮组；
- **POV 轨道名翻译**（三模式）：
  - 第三方优先（默认）：完全用外部插件翻译，BCP 表不介入
  - BCP优先：完全用 BCP 翻译表，不调外部插件
  - 第三方为主，BCP辅助：先外部插件，没覆盖的用 BCP 补充
- **POV Actions 属性面板翻译**（三模式）：同上
- **伪装选取**（二选一）：第三方优先 / BCP优先（无主辅模式）

### 调试日志链路

关键节点可从 `latest.log` 检索（搜 `BCP-`）：
- `BCP-PovTranslator`：翻译表初始化条数、第三方反射绑定结果、首次翻译模式记录
- `BCP-KeyframeSheet`：hook 首次触发记录
- `BCP`：冲突检测各功能来源数统计

### 实现要点

- 新增 `BcpConflictDetection` 设置类：三组按钮 + 来源计数检测
- 新增 `BcpModeValue` / `BcpModeValueUi`：循环按钮值类型与 UI 渲染
- 修改 `BcpPovTrackTranslator.translate()`：根据设置值决定优先级
- 两个翻译 mixin 移除旧 Cubed 开关判断，由 BCP 设置接管

## V1.7（2026-10-27）【正式版・V1.7.x-Alpha 实验成果整合转正】

V1.7.x-Alpha 实验线中**验证成功、不再回退**的核心功能整合为正式能力（V1.6.2 的下一正式版基线）：

### 核心功能：POV 插件中文翻译补充

针对 Cubed（BBS-Cubed）插件的「中文关键帧轨道名称」开关不翻译 POV 插件内容的问题，本插件做了补充性翻译补丁：

- **轨道名翻译**：hook `UIKeyframeSheet.applyStyle()`，当 Cubed 开关打开时，自动翻译 POV 时间轴子页（hotbar、Hand、POV Action）的轨道名；
- **右键菜单翻译**：hook `UIClips.getClipDisplayName(Clip)`，翻译 POV Action 右键菜单里的 9 个 action 类型名（GUI、Menu、Camera Shake、Particle Effect、Boss Bars、Status Effects、Toasts、Chat、Screen Effect）；
- **属性面板翻译**：hook `StringKey.get()`，翻译 POV Action 属性面板里的大量 label 文字（覆盖 200+ 条显示名，包括各个 action 的属性面板）；
- **预防性补丁**：翻译时优先调用 Cubed 的 `KeyframeLocalizer.localize(id)`，如果 Cubed 已覆盖则用 Cubed 的结果，只有 Cubed 没覆盖到的才用本插件的翻译表，避免未来冲突崩溃。

### 已知未覆盖（后续迭代）

以下字符串是直接硬编码在 UI 里的，不是通过 `IKey` 包装的，当前 hook 不到：
- 菜单设置按钮：`Menu: Sleep` 等；
- GUI 设置按钮：`GUI: Inventory` 等；
- GUI 类型选择弹窗里的类型名；
- 弹窗预设里的弹窗类型。

### 实现要点

- 新增翻译类 `BcpPovTrackTranslator`：200+ 条翻译表 + Cubed 开关检测 + 预防性 Cubed 优先翻译；
- 新增 mixin `UIKeyframeSheetPovLocalizerMixin`：hook `UIKeyframeSheet.applyStyle()` 翻译轨道名；
- 新增 mixin `UIClipsPovDisplayNameMixin`：hook `UIClips.getClipDisplayName(Clip)` 翻译 clip 显示名；
- 新增 mixin `StringKeyMixin`：hook `StringKey.get()` 翻译属性面板 label。

### 插件兼容适配

- **addon 检测**：启动时自动检测 lezy、POV、Cubed 三个附加插件是否安装，日志输出检测结果；
- **鼠标事件冲突**：与 Cubed 的 `mouseClicked` 冲突时，本插件优先（以我们的插件为主）。

详细条目见 `更新日志-V1.7.13-Alpha.md`（如已归档）。
