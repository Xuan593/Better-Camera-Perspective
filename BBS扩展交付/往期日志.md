## v1.4.0-BETA【Cubed 作者：一阵泠风】精加工源码合并版

* **主体合并**：以 BBS Cubed 作者发来的精加工源码（better-camera-perspective-v1.3.2-BETA-sources）为主，覆盖整合全部源代码文件
* **删除**：与 BBS Cubed 的冲突预防式更新内容 —— 冲突功能设置页 / 冲突检测弹窗系统（BcpConflictManager、BcpConflictChoiceRow、BcpConflictOverlayPanel、UISettingsLayoutMixin）整体移除
* **保留（一阵泠风 精加工）**：
  * 添加剪辑右键菜单项水平尺寸压缩至 **66px**，支持 **Ctrl + 滚轮切换列数（1~5）** 与滚动容器
  * 剪辑条显示开关回归：「摄像机编辑设置」→「剪辑处理设置」（剪辑名称显示 / 剪辑边界线 / 剪辑类型配色，默认全开）
* **保留（原版精进）**：时间轴剪辑条（轨道）占用长度减半 —— 默认厚度 20px→10px，Alt + 滚轮缩放范围 12~48→6~24（UIClipsLayerHeightMixin）
* **保留（原版修复）**：添加剪辑预览虚线框残留修复（UIRemovedEvent 清理 addPreview，Cubed 版已包含）
* **更名**：`better-camera-perspective-v1.4.0-BETA.jar`【此后的更新以此版为基础】

## v1.3.3（残留虚框修复 + 剔除剪辑处理设置）

* **修复**：删除剪辑 / 关闭添加菜单后时间轴上滞留的「添加剪辑」虚线选框
  * 根因：接管 `UIClips.showAddClips` 时直接以自定义菜单实例替换原生右键菜单，绕过了原版 `ContextMenuManager.onClose` 清理逻辑 —— 原生在菜单关闭时把 `addPreview`（添加预览框）置空，而本插件未补回，导致预览框残留并每帧绘制，只有重进编辑器（重启）才消失
  * 已按原版语义补回：菜单注册 `UIRemovedEvent` 监听，菜单关闭（选中剪辑 / ESC / 点击外部）即清理 `addPreview`；同时保留添加后立即清理，双保险
* **剔除**：设置页「剪辑处理设置」分类（判定为无用内容）
  * 移除「冲突功能」分类下方的 4 个开关：调整剪辑可见性 / 剪辑名称显示 / 剪辑边界线 / 剪辑类型配色
  * 删除对应语言键（中 / 英）与相关 Mixin（整理剪辑动画、剪辑条渲染），剪辑条显示恢复 BBS 原版默认行为（名称、边界线、类型配色正常显示，无整理动画）
  * 不影响其他功能：多样追踪、可视性设置、冲突功能设置页与弹窗全部保留
* **削减**：时间轴剪辑条（轨道）占用长度减半 —— 轨道厚度默认 20px → 10px（重进编辑器生效），Alt+滚轮缩放范围 12~48 → 6~24；添加剪辑右键菜单布局保持不变（每列 10 个）
* **更名**：`better-camera-perspective-v1.3.3.jar`

## v1.3.1（冲突功能设置页 + 逐功能弹窗）

* **新增**：BBS「设置」新增设置页 **「冲突功能」**（图标沿用摄像机视角图标）
  * 自动检测所有冲突功能并逐一排列，每项分隔列出功能名 + 该功能全部来源 Mod 按钮
  * 用户**逐功能**选择模式（并非清一色的全局 A/B 二选一）；点击来源按钮即选中（✓ 前缀标记当前模式）
* **重构**：冲突弹窗与设置页共用同一布局 —— 检测到以下同一功能有多个 MOD 来源 → 逐功能列出 + 来源 Mod 按钮 + 居中「完成选择，开始应用」，减少"选完确定后无窗口再次弹出导致后续异常"与崩溃退出几率（第一道墙）
* **通用化**：冲突管理升级为**通用冲突注册表**（BcpConflictManager）
  * 功能注册表目前含：剪辑可见性筛选（本插件 vs BBS Cubed），后续新增同类冲突可扩展注册
  * 配置迁移：旧全局 `conflict:{chosen}` 自动迁移为 `conflicts.<功能>.chosen`
* **更名**：`better-camera-perspective-v1.3.1.jar`

## v1.1（主继承模式按钮）

* **新增**：XYZ 双值面板行首两个锁定按钮升级为「主继承模式」开关
  * 默认激活「相对值」—— 按钮高亮显示「将主继承相对值」；点击「绝对值」按钮 —— 高亮显示「将主继承绝对值」
  * 切换只影响后续新建关键帧继承哪个值，不影响当前关键帧与视角；相对 / 绝对双值联动不变
* **新增**：新建关键帧按主继承模式供给值
  * 相对值模式：继承该 tick 的通道插值（相对偏移）
  * 绝对值模式：继承 插值 + 该 tick 追踪锚点（绝对坐标）
* **实现 / 修复**：
  * 打点注入：`UIKeyframeDopeSheetMixin`（HEAD 注入 + 手动重放 BBS 打点逻辑，仅调用类 / 字段 public 成员）
  * 继承兜底：XYZ 通道 seed（无插值段 / 自动记录路径）
  * 构建期排查两次运行时崩溃：`@ModifyArg` + 完整描述符 → 无 refmap → 注入失败崩溃 → 改为简单名 HEAD 注入；`@Shadow` 绑定接口 default 方法（IUIKeyframeGraph.addKeyframeManually）→ 运行时 InvalidMixinException → 改为手动重放打点逻辑（不 shadow 接口成员）
* **更名**：`better-camera-perspective-v1.1.jar`

## v0.3（anchor 追踪轴）
