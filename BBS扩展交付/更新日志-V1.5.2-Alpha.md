# 更新日志 - better-camera-perspective-V1.5.2-Alpha

> 排序：最新 → 最旧

## V1.5.2-Alpha

### 模式选项改为三个可选按钮（选中即应用）

* 两个子设置页（「关键帧处理设置」「可视化设置」）内的模式选项，由**单个黄色循环按钮**改为**三个并列可选按钮**：
  * 点击任一按钮即选中并应用（立即写入配置）；
  * 选中按钮以**黄色背景**标识，未选中为深灰背景，选中 / 未选中一眼可辨；
  * 按钮上方说明文本保留（说明该按钮用于干什么）。
* 实现：BcpModeValueUi 由 UICirculate 循环按钮重构为三枚 UIButton 并列布局（选中黄 0xFFFFC107 / 未选中深灰 0xFF2A2A2A）。

### 「混合」模式替换为「静态」模式（隐藏剪辑保留原位）

* **成因**：原「混合」模式（保持原始动态布局并叠加分类排序）实际视觉效果与「原始」一致、没有区别，判定无效；同时有用户反馈——可视性筛选操作中，被隐藏的剪辑会被滑到最后，容易不小心误伤其他可能排上用场的剪辑。
* **「预新建剪辑可视化」第三模式改为「静态」**：
  * `[原始]`（原始状态）—— 筛选后列表自动重新排列（可见剪辑排前，隐藏剪辑沉底）；
  * `[覆盖]` —— 三列分类菜单布局（作用于右键添加剪辑菜单）；
  * `[静态]` —— 被隐藏的剪辑在可视性筛选界面中的**布局位置不变**（筛选后不重排）。
* 实现：BcpClipProcessing 第三模式 mixed → static；BcpVisibilityOverlayPanel 静态模式下取消可见性排序；UIClipsAddClipMixin 移除混合模式分类排序分支（原始 / 静态共用自适应多列菜单）。

### 可视性筛选界面尺寸削减 40%

* 可视性设置面板（overlay）水平、垂直尺寸各削减 40%：460×440 → **276×264**（剪辑列表 3 列网格 + 滚动保持不变）。
