# 更新日志 - better-camera-perspective-V1.5.2-Alpha

> 排序：最新 → 最旧

## V1.5.2-Alpha（第 2 次修订）

### 拆分「可视化设置」为两个独立设置项（修复误合并）

* **成因**：首版把「预创建剪辑菜单布局」与「可视性筛选排布」两个功能的选项误合并成一组三选一按钮。
* **现在拆为两组**（均为三个并列可选按钮 / 两个并列可选按钮，选中即应用，选中黄色背景、未选中深灰）：
  * **预创建剪辑可视化**：`[原始]`（原始状态）/ `[覆盖]`（三列分类布局）/ `[混合]`（保持原始动态布局，并按分类排序 + 着色）；
  * **可视化筛选排布**：`[动态]`（筛选后重排，隐藏剪辑沉底）/ `[静态]`（被隐藏的剪辑在此界面的布局位置不变）。

### 修复「混合」模式与「原始」无视觉区别

* **成因**：此前「混合」仅按分类排序，与原厂顺序视觉近似，用户反馈"选混合后与原始一致，没有区别"。
* **现在**：「混合」模式按分类（覆盖 → 修改器 → 杂项）排序，并**按分类着色**（覆盖蓝 / 修改器绿 / 杂项灰），与「原始」有明确视觉区别。
* 实现：UIClipsAddClipMixin 混合分支按 ClipCategory 排序 + ColorfulContextAction 着色；ClipCategory 新增 colorOf()。

### 模式选项改为三个可选按钮（选中即应用）

* 两个子设置页内的模式选项，由单个黄色循环按钮改为**并列可选按钮**：
  * 点击任一按钮即选中并应用（立即写入配置）；
  * 选中按钮以**黄色背景**标识（0xFFFFC107），未选中为深灰背景（0xFF2A2A2A）；
  * 按钮上方说明文本保留。
* 实现：BcpModeValueUi 由 UICirculate 循环按钮重构为多枚 UIButton 并列布局。

### 可视性筛选界面尺寸削减 40%

* 可视性设置面板（overlay）水平、垂直尺寸各削减 40%：460×440 → **276×264**（剪辑列表 3 列网格 + 滚动保持不变）。
