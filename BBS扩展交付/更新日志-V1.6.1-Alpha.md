## V1.6.1-Alpha（2026-10-20）

【实验版・多样追踪新关键帧轴「相位追踪」初版】

> **版本关系**：V1.6.1-Alpha 是基于 V1.6.0（正式版）之上的**实验迭代**，新增功能尚未完全定稿，按实验线保留；
> 如验证成功将整合进后续正式版。V1.6.0 仍是当前正式版本基线，二者并不冲突。

### 新功能：相位追踪（关键帧轴，默认关）

在「多样追踪」剪辑中新增一条关键帧轴 **相位追踪**（值面板：开关 + 跟随强度），每帧独立开关：

- **关（默认）/ 开**：开启时，读取当前摄像机的跟踪模式与相对 / 绝对坐标（即关键帧驱动的最终机位），以及被追踪演员（伪装）的相关坐标，自动把摄像机朝向平滑转向演员，实现**非完全锁定式的自动效果跟踪**——摄像机位置不被修改（仍由关键帧曲线 / 游动 / 追踪驱动），只有朝向（偏航 / 俯仰）被接管，尽可能减少视角之间的不平滑；
- **被追踪演员取法**：与追踪路线一致 —— anchor 轴当前关键帧绑定谁就盯谁；无绑定（`<无>` / 无 anchor 帧）回退剪辑属性「追踪目标」；
- **可能性一（演员动、机位不动）**：演员从 (0,0,0) 移到 (0,0,10)，而摄像机关键帧保持原位 —— 摄像机在**不跟随移动**的状态下持续转头盯住演员，完成跟踪录制；
- **可能性二（演员机位同动）**：摄像机关键帧同步从 (0,0.5,10) 移到 (0,0.5,-10) —— 摄像机在被移动的过程中时刻追踪演员，完成丝滑视角录制；
- **跟随强度（0~1，默认 0.9）**：1 = 完全盯住演员；0 = 保持关键帧朝向（等同关闭）；调低可获得更柔和的部分跟随。播放端会将该值约束在 0~1；
- **不干预项**：摄像机位置、横滚（roll）、视野（fov）均不参与相位追踪；目标解析失败 / 开关关闭 / 无关键帧时完全不干预画面（无目标回退「关」）。

### 实现要点（单独类属性，避免污染）

- 新增帧级数据类 `PhaseFrameData`（开关 + 跟随强度）与 `PhaseFrameDataKeyframeFactory`（类型名 `bcp_phase_frame`），**与 xd/yd/zd 的 `XyzFrameData` 完全分离存储**，每帧独立，不共用数值池，杜绝游动 / 追踪 / 相位之间的相互污染；
- 新通道 `phase` 已加入服务端 / 客户端剪辑注册表，工厂在启动时注册进 BBS 全局 `KeyframeFactories`（**务必保持类型名稳定，否则旧存档读不回**）；
- 播放端在关键帧求值（游动 / 追踪世界坐标）之后接入：以**最终机位**为参考解析演员相对方向，按 BBS 原生 lookAt 同口径计算朝向，再以「最短弧 + 跟随强度」插值，避免开关切换瞬间的突兀跳变（角度最短弧过渡）；
- 时间轴新增「相位追踪」行（亮紫标识），选中关键帧可编辑开关与跟随强度；新建关键帧默认「关」。
