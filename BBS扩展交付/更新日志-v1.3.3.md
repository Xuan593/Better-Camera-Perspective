# Better camera perspective 更新日志

## v1.3.3（残留虚框修复 + 剔除剪辑处理设置）

* **修复**：删除剪辑 / 关闭添加菜单后时间轴上滞留的「添加剪辑」虚线选框

  * 根因：接管 `UIClips.showAddClips` 时直接以自定义菜单实例替换原生右键菜单，绕过了原版 `ContextMenuManager.onClose` 清理逻辑 —— 原生在菜单关闭时把 `addPreview`（添加预览框）置空，而本插件未补回，导致预览框残留并每帧绘制，只有重进编辑器（重启）才消失

  * 已按原版语义补回：菜单注册 `UIRemovedEvent` 监听，菜单关闭（选中剪辑 / ESC / 点击外部）即清理 `addPreview`；同时保留添加后立即清理，双保险

* **剔除**：设置页「剪辑处理设置」分类（判定为无用内容）

  * 移除「冲突功能」分类下方的 4 个开关：调整剪辑可见性 / 剪辑名称显示 / 剪辑边界线 / 剪辑类型配色

  * 删除对应语言键（中 / 英）与相关 Mixin（整理剪辑动画、剪辑条渲染），剪辑条显示恢复 BBS 原版默认行为（名称、边界线、类型配色正常显示，无整理动画）

  * 不影响其他功能：多样追踪、可视性设置、冲突功能设置页与弹窗全部保留

* **更名**：`better-camera-perspective-v1.3.3.jar`

## v1.3.1-Fix（冲突功能设置页修正）

* **调整**：冲突功能选择改为 **选中即应用** —— 移除页末「应用」按钮（及其占位配置项），点击来源 Mod 按钮即立即生效并持久化

## v1.3.1（冲突功能设置页 + 逐功能弹窗）

* **新增**：BBS「设置」新增设置页 **「冲突功能」**（图标沿用摄像机视角图标）

  * 自动检测所有冲突功能并逐一排列，每项分隔列出功能名 + 该功能全部来源 Mod 按钮

  * 用户**逐功能**选择模式（并非清一色的全局 A/B 二选一）；点击来源按钮即选中（✓ 前缀标记当前模式）

* **重构**：冲突弹窗与设置页共用同一布局 —— 检测到以下同一功能有多个 MOD 来源 → 逐功能列出 + 来源 Mod 按钮 + 居中「完成选择，开始应用」，减少"选完确定后无窗口再次弹出导致后续异常"与崩溃退出几率（第一道墙）

* **通用化**：冲突管理升级为**通用冲突注册表**（BcpConflictManager）

  * 功能注册表目前含：剪辑可见性筛选（本插件 vs BBS Cubed），后续新增同类冲突可扩展注册

  * 配置迁移：旧全局 `conflict:{chosen}` 自动迁移为 `conflicts.<功能>.chosen`

* 构建产物：better-camera-perspective-v1.3.1.jar/-sources.jar
