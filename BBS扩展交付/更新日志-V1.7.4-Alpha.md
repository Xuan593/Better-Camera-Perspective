## 新增

### POV 轨道名中文翻译补丁

当 Cubed 的「中文关键帧轨道名称」开关打开时，自动将 POV 时间轴子页的轨道名翻译为中文。

**已翻译的 POV Action 轨道**（9 个）：
- gui → GUI界面
- menu → 菜单
- camera_shake → 相机震动
- particle_effect → 粒子效果
- boss_bars → Boss血条
- status_effects → 状态效果
- toasts → 弹窗通知
- chat → 聊天栏
- screen_effect → 屏幕特效

**待补充**：hotbar 子页、Hand 子页的轨道名（需游戏内实测补充）。

## 测试

1. 安装 Cubed + POV + 本模组
2. 打开 Cubed 设置 → 开启「中文关键帧轨道名称」
3. 打开影片编辑器 → POV 时间轴 → 查看轨道名是否变为中文
