## v1.2-Alpha（2026-10-07）【实验性更新】

**新增 1：设置页「camera perspective」（剪辑可见性筛选）**



* BBS 设置界面新增设置页「camera perspective」（图标沿用摄像机编辑器视角图标）：


  * 可在其中按剪辑类型自由开关「摄像机编辑器右键添加剪辑菜单」中各剪辑的可见性；

  * 关闭后该剪辑不再出现在右键添加菜单中，减少过多剪辑占用的视觉空间；既有剪辑数据与功能不受影响；

  * 借鉴 BBS 源码中「筛选轴可见度」的思路（设置值 + 菜单构建时过滤）。

**新增 2：新剪辑「特效移植」（fx\_port）—— 把后期工作搬到前期**



* 用法：关键帧编辑 → 对应功能轴 → 轴关键帧 → 关键帧属性，设置对应属性；

* 特效类型（剪辑属性）：色度转场 / 模糊转场。

**色度转场（单色度 / 渐变双色度）**



* 单色度转场：剪辑一某帧画面 → 单色度 → 剪辑二某帧画面（或剪辑一 tick 靠后的另一帧画面），色度不局限于黑 / 白，可自选任意色；

* 渐变双色度：画面 → 色度一 → 色度二 → 目标画面；若两色度选同一色度或有一色度为空，按单色度逻辑处理；

* 相关轴：color1（起始色度）、color2（结束色度）、amount（覆盖度，用于控制转场进出）。

**模糊转场（纯视觉功能效果移植）**



* 全面指向模糊：某帧画面 → 模糊 → tick 靠后的某帧画面（普通模糊特效，blur 轴控制强度）；

* 点扩散模糊：轴关键帧属性中提供两个可编辑值：


  * X 轴向（水平）、Y 轴向（垂直）；两者归零时初始点位于预览画面正中心；

* 两个可编辑值下方为「扩散模式」可选框：


  * 基础（全面指向模糊，默认）；

  * 扩散（先帧由点向外扩散进行模糊，后帧由点向外扩散恢复清晰 —— 空间上中心清晰、边缘模糊）；

  * 收缩（先帧由外向点收缩进行模糊，后帧由外向点收缩恢复清晰 —— 空间上中心模糊、边缘清晰）；

* 「扩散类型」可选框（扩散模式非「基础」时解除下方锁定并被应用）：


  * 圆形（默认）：模糊视觉效果呈现圆的放大或缩小；

  * 百分比：按分辨率进行百分比计算（读取设置的导出分辨率与预览分辨率；例：1920×1080 下 ±1920 为水平 100%、±1080 为垂直 100%，轴模糊影响双向）；

  * 表达式（实验品中的实验品）：可自行编写表达式实现方形扩散、菱形扩散等效果（变量 x = 水平方向分量、y = 垂直方向分量、r = 距中心欧氏距离，返回 0..1 权重）；

* 相关轴：blur（模糊强度）、blurX /blurY（点扩散中心偏移）、spreadMode（扩散模式）、spreadType（扩散类型）、expr（扩散表达式）。

**实现**



* 画面叠加走 BBS 公开扩展点 `FrameOverlays.register`（无需侵入核心渲染）：


  * 色度转场：画面之上绘制全屏色度（单色度 / 水平渐变双色度，24 段插值）；

  * 模糊转场：对当前主 framebuffer 执行 GL 后期（framebuffer → 模糊 shader → 临时 FBO → 写回），预览与导出 / 截图均生效；表达式按需编译并缓存 shader；

* 剪辑菜单筛选：`UIClipsAddClipMixin`（接管 showAddClips，仅过滤一步，逻辑与原实现一致）；

* 设置模块：`BcpSettingsModule`（RegisterClientSettingsEvent + BBSMod.setupConfig，开关以剪辑类型为粒度持久化）。

**实验性说明**



* 模糊转场为纯视觉效果移植，模糊作用于画面帧（预览 / 导出），不改变场景与相机数据；

* 表达式功能为实验品中的实验品（悬浮提示「实验品中的实验品，你当真要用？」），表达式不合法时跳过该帧模糊。

**更名**



* `better-camera-perspective-v1.2-Alpha.jar`

## v1.1（2026-10-06）

**新增**



* XYZ 双值面板行首两个锁定按钮升级为「主继承模式」开关：


  * 默认激活「相对值」—— 按钮高亮显示「将主继承相对值」；

  * 点击「绝对值」按钮 —— 高亮显示「将主继承绝对值」；

  * 切换只影响后续新建关键帧继承哪个值，不影响当前关键帧与视角；相对 / 绝对双值联动不变。

* 新建关键帧按主继承模式供给值：


  * 相对值模式：继承该 tick 的通道插值（相对偏移）；

  * 绝对值模式：继承 插值 + 该 tick 追踪锚点（绝对坐标）。

**实现 / 修复**



* 打点注入：`UIKeyframeDopeSheetMixin`（HEAD 注入 + 手动重放 BBS 打点逻辑，仅调用类 / 字段 public 成员）。

* 继承兜底：XYZ 通道 seed（无插值段 / 自动记录路径）。

* 构建期排查两次运行时崩溃：

1. `@ModifyArg` + 完整描述符 → 无 refmap → 注入失败崩溃 → 改为简单名 HEAD 注入；

2. `@Shadow` 绑定接口 default 方法（IUIKeyframeGraph.addKeyframeManually）→ 运行时 InvalidMixinException → 改为手动重放打点逻辑（不 shadow 接口成员）。

**更名**



* `better-camera-perspective-v1.1.jar`

## v1.0（2026-10-04）

**改动（大改）**

* XYZ 关键帧值面板改为「绝对值 + 相对值」双值联动：

## v0.3（Alpha-0.3，2026-10-04）

**新增**

## v0.1（0.1-Alpha，2026-10-02）

**新增**



* 新增剪辑「多样追踪」（multi\_tracker）：追踪器 + 关键帧二合一。


  * 继承「关键帧」剪辑的 8 个数值通道（X / Y / Z / 偏航 / 俯仰 / 横滚 / 视野 / 距离）与 additive 叠加开关；

  * 携带「追踪器」剪辑全部追踪参数（目标 / 附件 / 偏移 / 角度 / 看向目标 / 相对 / 启用位掩码）；

  * 「启用位掩码」6 位：位 0-2 = X/Y/Z 位移跟随，位 3-5 = 偏航 / 俯仰 / 横滚跟随，默认全开 = 纯追踪器；关掉某位后该轴改由关键帧曲线驱动。

* 拖动相机编辑：先按追踪器反解偏移 / 角度，再把相机位置写入关键帧曲线。

**修复**



* 锚点关键帧绑定其他演员时显示一串数据码：初版修复（formId 反查显示演员名）。
