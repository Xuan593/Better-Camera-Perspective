## V1.5-Alpha

### 新增「关键帧处理设置」分类 —— 关键帧被选中状态三模式

**成因**：个人使用期间，一段时间内新建的所有关键帧都会处于被选中状态（连建 3 个，三个都处于被选中），选中状态卡手。



* 设置页（红圈分类导航）新增子分类 **「关键帧处理设置」**（分类悬停有功能说明文本）：


  * **关键帧被选中状态** 三模式（循环按钮）：


    * `[默认]`（原始处理设置）—— 新建关键帧后全部保持选中（原行为）

    * `[单体]` —— 每新建一个关键帧自动解除上一个关键帧的选中状态

    * `[混合]` —— 前两者的智能融合：连续新建只保留最新帧选中，手动选中的帧不受影响（按通道记忆上次新建的帧，仅解除该帧）

* 实现：设置值 BcpKeyframeProcessing + 通用三态循环按钮（BcpModeValue / BcpModeValueUi）；UIKeyframeDopeSheetMixin 打点后按模式处理选中状态

### 新增「可视化设置」分类 —— 预新建剪辑可视化三模式



* 原「剪辑处理设置」分类更名 **「可视化设置」**（黄圈分类）。

* 新增 **「预新建剪辑可视化」** 三模式（循环按钮）：


  * `[原始]`（原始状态）—— 原自适应多列动态布局（66px 单元格 / Ctrl + 滚轮切列 1\~5）

  * `[覆盖]`（转发截图式布局）—— 参考强援 FS2.8 体验截图：顶部搜索框 + 「覆盖 / 修改器 / 杂项」三列分类菜单（分类标题着色，搜索即时过滤重建）

  * `[混合]` —— 保持原始动态布局（多列自适应），并叠加分类功能：剪辑按分类（覆盖 → 修改器 → 杂项）排序

* 剪辑分类规则：覆盖 = 静止 / 路径 / 关键帧 / 追踪器 / Spline / 多样追踪 / 跟随 / 闲置；修改器 = 平移 / 角度 / 阻力 / 摇晃 / 数学 / 重映射 / 看 / 轨道 / 滑动变焦 / 电影；其余归杂项兜底

* 「可视性设置」仍恒定位于右键菜单 **1 号位**（覆盖模式下位于列 1 顶部）

* 实现：BcpCategorizedClipMenu（搜索框 + 三列分类菜单）+ ClipCategory 分类工具；UIClipsAddClipMixin 按可视化模式构建菜单
